# Countdown Timer

A simple countdown timer application built with Next.js and React Context API.

## Features

- Server-Side Rendering with Next.js.
- Context-based state management for the countdown.
- Configurable countdown time via environment variables.
- Real-time countdown display.

## Getting Started

1. Clone the repository.  
2. Run `npm install` or `yarn install`.
3. Copy `.env.template` to `.env.local` and set `REACT_APP_COUNTDOWN_TIME`.
4. Start the development server with `npm run dev` or `yarn dev`.

## Usage

- Adjust the countdown time in `.env.local`.
- Access the timer at `http://localhost:3000`.
- The countdown automatically starts and updates in real-time.
